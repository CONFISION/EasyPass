# EasyPass 3.1.0

## 新增

- 智能体访问（MCP）：本机回环接口、配对密钥；逐次审批/可信直通；条目级「开放/永久拒绝」（仅登录、安全笔记；身份/SSH 硬拒）；11 个工具；秘密只进剪贴板；新增审计页。
- 回收站：删除改为可恢复软删，支持恢复、彻底删除、清空；列表、搜索、健康、导出默认排除。
- 字体子集化，安装包更小、启动更快。

## 修复

- 审批：执行前重读条目/配对/总开关，防旧快照覆盖；超时/锁屏按拒绝；防双击批错；详情显示旧→新（无秘密）。
- 会话/密钥：智能体会话不再 5 分钟空闲锁；改主密码时重包裹与轮换同事务；解封失败即停 MCP。
- 传输/存储：固定端口占用即不启动；拒绝跨源/非回环 Host/非 POST；先认证后读 body；schema 4→5 迁移事务化、幂等；导入清洗；剪贴板重试；daemon.json 原子写、损坏即拒绝。
- UI：徽标左对齐、窄窗不溢出；设置、列表、详情、审计页刷新修复。
